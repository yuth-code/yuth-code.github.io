dlp

Yuth AI Guard

Browser extension that stops sensitive data from reaching AI chatbots. Intercepts the outbound request across 15 platforms (ChatGPT, Claude, Gemini, Copilot…) and blocks it in-browser if the message contains PII, API keys, source code, or health identifiers — 30+ client-side rules, zero data exfiltration, violations logged to an admin dashboard.

Approach: Interception happens at the network layer, not the DOM — the request is cancelled before it reaches the provider, so detection can't be raced by the page. Rules are tuned against false positives: ID numbers require their real separator format, phone numbers require a country prefix, and source-code rules need actual syntax so asking about SQL doesn't trip the SQL rule.

Impact: Two builds — a policy-managed one for users and an admin one with per-rule toggles. Every block and every "allow once" override is logged, so the dashboard shows which platforms and which data types actually leak instead of guessing. Legitimate sends stay possible; they just stay auditable.

Stack: Chrome Extension (MV3) · Firestore · 5 rule categories

jadx

AI-Powered Static RE Lab

Self-hosted lab for AI-assisted static reverse engineering of Android builds. Upload an APK/AAB/DEX and it decompiles with jadx, deep-decompiles native .so libs via Ghidra headless, sweeps for hardcoded secrets, endpoints and insecure API usage, runs semgrep/mobsfscan/apkid, then an AI agent explores the tree and returns a structured findings report — CVSS computed in code, never by the model. Also diffs two versions of the same app.

Approach: Deterministic tooling first, model last. jadx, Ghidra headless and radare2 produce the artifacts; a secret/endpoint sweep plus semgrep, mobsfscan and apkid seed the triage; only then does the agent read the tree. Scanners run under hard bounds — taint analysis on R8's merged multi-MB classes OOM-kills the engine, and that failure is indistinguishable from a clean scan, so a zero-file scan is reported as an error rather than a result.

Impact: CVSS is computed in code from the finding's category and severity, never emitted by the model — severity drift across repeat runs on an unchanged build was measured on this lab, and a model-authored score would have dressed that drift up as precision. "Control not detected" results are quarantined instead of reported as missing controls, because obfuscated builds rename the symbols those rules look for. Every report leads with what was not tested.

Tools: jadx · Ghidra headless · radare2 · semgrep · mobsfscan · apkid · Claude Agent SDK
